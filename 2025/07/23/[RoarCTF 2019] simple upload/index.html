我们发现ThinkPHP3.2版本有一个PATHINFO模式

PATHINFO地址的前三个参数分别表示模块/控制器/操作。

示例:http://localhost/index.php/home/user/login?var=value

参考上面的 URL 链接

模块 –> home

控制器 –> user

操作方法 –> login

变量 –> var

3，文件上传

我们到了这一步大概也可以搞清楚他要我们写一个脚本来上传文件，我么再次分析一下源码可以了解到，虽然文件上传限制了.php后缀，仔细看才发现，这个过滤逻辑它只会进行一次，我们可以一次性上传多个文件，这样他就追回对第一个文件进行过滤，后面的文件就可以通过了，但是上传成功后回显的是，第一个上传 的文件的地址，而不会打印我们上传的一句话木马的地址，但是我们发现ThinkPHP3.2会自动地对上床成功的文件进行重命名，他的地城逻辑是保存的文件名：随机字符串 + 时间戳 + 后缀名，两个文件上传时间近可以通过爆破得到我们上传的shell的文件名。

我们先来写一个代码来进行文件上传（使用python来写上传文件的脚本主要原因是python的检测速率高，且对进行文件的批量上传有显著的简便相比较与其他语言。）

我们看一下结果

发现他只会显示出我们上传的的第一个文件的名称，第二个文件时显示不出来的，但是我们根据这个文件的命名方法可以对文件名进行爆破，经过对这个重命名方式的了解我们只需要对随机生成的16位字符的后三位进行爆破就行。（前面的是根据时间生成的时间戳同时上传一样，后面的三个数书随机生成的随机数）
